Place the NASA C-MAPSS FD001 files here before training and seeding:

    train_FD001.txt
    test_FD001.txt
    RUL_FD001.txt

They are in "CMAPSSData.zip" (Turbofan Engine Degradation Simulation Data Set) on the NASA
Prognostics Center of Excellence data repository. If they are missing, a synthetic FD001-like
data set is generated instead and every result is labelled "SYNTHETIC".
